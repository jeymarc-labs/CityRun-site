Common Questions

The map is blank. A city's map downloads the first time you open its route map, which needs a connection once. After that it works offline. If it stays blank, check Settings › Downloaded data to see whether the map is there.

Narration is not playing. Check that your phone is not on silent, and that the route does not show a “Narration coming soon” badge — some routes are still being recorded.

My run did not save. RunCity keeps a running backup, so if the app closed mid-run it will offer to recover the run the next time you open it.

How do I delete my data? Delete an individual run from the My Runs tab, or delete the app to remove everything — all of your RunCity data lives on your phone. Downloaded maps can be removed separately in Settings › Downloaded data.
